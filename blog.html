Project note

Smart Car Rental: building the customer side of a rental system

This C# Windows Forms module covers everything a customer does: register and log in, browse and filter cars with images, book and cancel a rental, pay, and look back at booking history and profile.

Building one role end to end taught me to think in full user journeys instead of single screens, and to keep the forms and the SQL Server database working together as one system.

  • C#
  • Windows Forms
  • SQL Server

Project note

Tkinter Clock App: five tools in one window

Instead of opening a separate window for each tool, this app puts a digital clock, stopwatch, alarm, timer and searchable world clock in one window and switches between them from a sidebar.

It was a good exercise in organizing a desktop interface so that a small Python project still feels like a real application.

  • Python
  • Tkinter

Project note

QR Code Generator: a small command-line tool

This lightweight app takes a URL and turns it into a QR code saved as a PNG image, using the qrcode and Pillow libraries.

Small tools like this are a quick way to learn how to use third-party Python libraries and produce a useful output file.

  • Python
  • qrcode
  • Pillow
